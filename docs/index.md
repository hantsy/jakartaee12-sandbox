# Jakarta EE 12 Sandbox

A playground of new features in Jakarta EE 12, running on GlassFish 9 and Java 25.

## Modules

| Module       | Spec / API                                              |
|--------------|---------------------------------------------------------|
| `faces`      | Jakarta Faces 5.0.0-M5                                  |
| `servlet`    | Jakarta Servlet 6.2.0-M2                                |
| `persistence`| Jakarta Persistence 4.0.0-M6                            |
| `cdi`        | Jakarta CDI 5.0.0.CR1                                   |
| `security`   | Jakarta Security 5.0.0-M2 + GlassFish MP-JWT            |
| `hibernate`  | Hibernate ORM 8.0.0.Beta1 (Jakarta Persistence 4.0)     |

See the individual pages for details.
